# Server Monitoring

Backend-сервис для мониторинга доступности сайтов и DNS серверов. В нем реализована регистрация и аутентификация
пользователей, проведение регулярных проверок с заданной периодичностью и сохранение данных пользователей, отслеживаемых
серверов и результатов проверок в базу данных.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker


## Features

- мониторинг доступности сайтов и DNS серверов(DNS over HTTPS)
- сохранение данных в базу PostgreSQL
- регистрация и аутентификация пользователей с JWT токенами
- регулярные проверки с заданной периодичностью
